install requirements bat file downloads ffmpeg.exe  and pytheon libraries needed to build the program.

ffmpeg.exe is needed for mp3 conversions if you want to download it manually you can do it here https://github.com/BtbN/FFmpeg-Builds/releases/latest/download/ffmpeg-master-latest-win64-gpl.zip just make sure to put it in the same folder as the pytheon code and the compilexe.bat file.
